# 🛒 Smart Store Checkout System

A backend solution that enables **checkout-free shopping** through **RFID integration**, **payment gateway processing**, and **real-time inventory tracking**. Developed during my time at **Mahendra NextWealth** for retail automation clients.

---

## 🔧 Tech Stack

- Java 8
- Spring Boot
- MySQL
- REST APIs
- Maven
- JUnit
- GitHub

---

## 🚀 Features

- RFID-based product scan recognition and backend processing.
- Secure and real-time payment gateway integration.
- RESTful APIs to handle cart operations and transaction logs.
- Inventory sync between RFID readers and database.
- Optimized queries and performance tuning.

---

## 🧩 Project Modules

- RFID Input Integration
- Product Lookup & Pricing Engine
- Payment Handling
- Inventory Sync Service
